# Nearbazar

A local marketplace where users can buy and sell items nearby.

## Features

- 🛍️ List items for sale
- 🔍 Search listings
- 📍 Nearby/local marketplace
- 📱 Mobile-friendly design
- 👤 Seller contact
- 🖼️ Item photos

## About

Nearbazar is a local marketplace designed to help people buy and sell items within their nearby area.
